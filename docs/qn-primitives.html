1. Physical Atomicity & The Silicon Gatekeeper

At the bare-metal hardware register level, software abstraction ends. The 64-bit Word (Qn,64) is the single, universal physical bit-atom of the Quang Number universe.

Every higher-level structure (Quang Expressions, Qm vectors, Qs knowledge graphs, and CDQN network packets) is constructed strictly by composing arrays of this single 64-bit register primitive.

The Silicon Gatekeeper Law: Lower(Data) ∉ { Qn,64 } ⇒ Qn = ∅ (Rejected at Hardware Register Interface)

2. Universal 64-Bit Register Format & Hardware Mappings

2.1 The Single Universal Bit-Atom (Qn,64)

Every device—from 32-bit microcontrollers up to 512-bit supercomputer vector engines—uses the exact same 64-bit bit-field contract:

UNIVERSAL Qn,64 PACKED REGISTER WORD (64 BITS TOTAL)
Bits 0 – 15 (16 Bits)
Security Anchor [S]
Bits 0-11: Origin Identity Hash (I_src/Epoch). Bits 12-15: HMAC Truncated Verification Proof (Σ).
Bits 16 – 31 (16 Bits)
Metric Anchor [M]
Bits 16-17: 2-bit Status. Bits 18-19: Domain. Bits 20-25: Scale z_macro. Bits 26-31: Resolution z_micro.
Bits 32 – 63 (32 Bits)
Value Payload [V]
16:16 Signed Numerator / Denominator ratio [N, D] or 32-bit Qexpr Arena Offset.

2.2 32-Bit Hardware Edge Alignment (r0:r1 Register Pair)

On 32-bit hardware architectures (ARM Cortex-M, ESP32, RISC-V RV32I), a 64-bit Qn,64 atom maps cleanly into a 2-register pair (`r0:r1`):

  • Control Register `r0` (Bits 0–31): Holds Security Anchor S (Bits 0-15) and Metric Anchor M (Bits 16-31). The CPU evaluates invariant checks in 1 clock cycle using register `r0`.
  • Data Register `r1` (Bits 32–63): Holds the 32-bit Value Payload V.

2.3 Multi-Lane SIMD Vector Register Scaling

Wider vector registers do not introduce new bit formats; they function as multi-lane SIMD vector arrays of Qn,64 atoms:

  • 128-Bit SIMD Register (ARM Neon / Apple AMX / WASM): Holds a 2-lane vector pair Qn,64[0] ‖ Qn,64[1].
  • 256-Bit AVX Register: Holds a 4-lane vector array of Qn,64 atoms.
  • 512-Bit Vector Engine: Holds an 8-lane vector array of Qn,64 atoms.

3. Execution Status Field & Zero-Day Isolation

Bits 16–17 in Qn,64 specify the 2-bit Execution Status Field, providing native hardware feedback for Soft Halting and Zero-Day threat isolation:

Status Code Symbolic Name Hardware Execution & BoC Action
00 VALID_EXACT Hard Halt (Remainder R = 0). Exact evaluation complete. Zero residual memory required.
01 VALID_RESIDUAL Soft Halt (Remainder R ≠ 0). Active view V_z returned; residual R persisted in Q(reuse) SRAM cache.
10 INVARIANT_FAULT Security S or Metric M failure. Triggers Null Law (Qn = ∅). Payload dropped at register interface.
11 ANOMALY_QUARANTINE Execution anomaly or zero-day pattern detected. Invokes BoC engine for network-wide immunization.

4. Hardware Alignment & Space-Time Dilation Rules

4.1 The 64-Byte L1 Cache Line Fit

To maximize L1/L2 memory cache throughput and eliminate bus transfer waste, a physical 64-byte silicon cache line fits EXACTLY 8 packed Qn,64 words (8 × 8 bytes = 64 bytes) with 0% padding waste.

4.2 Register Calling Convention

  • Operands: Passed in hardware registers r0 through r3.
  • Active View Output (V_z): Primary result returned in register r0.
  • Residual Output (R): Exact residual R returned in register r1 (persisted in Q(reuse) SRAM).
  • Status Flags: Written directly to condition code flags in the CPU status register.

4.3 Universal Endianness Standard

All binary payloads and memory structs mandate Little-Endian byte ordering as the universal standard across ARM64, RISC-V, x86_64, and WebAssembly.

5. Aperiodic Arenas & Substrate-Neutral SQS Transport

5.1 Aperiodic Einstein Tile Memory Allocation

Physical hardware RAM is partitioned using Aperiodic Monotiles (Einstein tiles / Quasicrystals). Memory arenas consist of contiguous arrays of Qn,64 words. Substitution and inflation depth indices are encoded inside zoom window z, eliminating periodic hash collisions and dynamic heap allocation overhead (malloc).

5.2 Substrate-Neutral SQS Transport ABI

To a Self-Quang System (SQS), the distinction between local hardware registers, memory buses, and remote network sockets is strictly a function of Latency (Δτ) and Addressing Space (I_src → I_dst).

The Qn,64 binary layout defined in this specification serves as the Universal SQS Payload Layout. A packed 64-bit Qn word can be executed directly inside a CPU register, copied to an SRAM arena, or transmitted across a network socket with zero re-serialization or translation loss.
