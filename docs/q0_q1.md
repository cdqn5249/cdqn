## 2. Layer 0 to Layer 1 Gateway: Node Onboarding Protocol

The {% include term.html id="simemp-gateway" %} bridging Layer 0 and Layer 1 enforces the physical-to-governed transition through a six-stage deterministic onboarding pipeline:

```
               NODE ONBOARDING STATE MACHINE
 [START]
    │
    ▼
 (Stage 1: Raw Entropy Harvesting) ──► Fault ──► [RECEIPT: ENTROPY_SOURCE_FAULT]
    │
    ▼
 (Stage 2: Health Tests NIST SP 800-90B) ──► Fault ──► [RECEIPT: ENTROPY_INSUFFICIENT]
    │
    ▼
 (Stage 3: Cryptographic Conditioning)
    │
    ▼
 (Stage 4: Inner-Ring PQC Key Generation) ──► Fault ──► [RECEIPT: PQC_KEYGEN_FAILURE]
    │
    ▼
 (Stage 5: Genesis Object Q(0) Assembly)
    │
    ▼
 (Stage 6: Sealing & Receipt Emission) ──► Fault ──► [RECEIPT: GENESIS_RECEIPT_FAILURE]
    │
    ▼
 [SUCCESS: NODE OPERATIONAL]
```

### 2.1. Stage 1: Physical Entropy Harvesting

The node interrogates native Layer 0 entropy sources:
- Silicon thermal noise, ring oscillator phase drift, or avalanche diode shot noise.
- Operating system hardware performance counters and interrupt timing jitter.
- The raw bitstream $\mathcal{B}_{\mathrm{raw}}$ must yield a minimum sample size of $N_{\mathrm{sample}} \ge 4096$ bits.

### 2.2. Stage 2: Statistical Health Tests

Before admission into the governed universe, $\mathcal{B}_{\mathrm{raw}}$ is evaluated against continuous on-line health tests conforming to NIST SP 800-90B:

- **Repetition Count Test:** Detects catastrophic hardware failure (stuck-at bits). Halts if an identical value repeats beyond threshold $C_{\mathrm{rep}}$.
- **Adaptive Proportion Test:** Detects statistical bias over moving windows of $W = 512$ samples. Halts if frequency exceeds critical cut-off $C_{\mathrm{adapt}}$.
- **Min-Entropy Bound:** The assessed Min-Entropy of the raw bitstream must satisfy the strict lower threshold:

$$H_{\mathrm{min}}(\mathcal{B}_{\mathrm{raw}}) \ge 0.85 \text{ bits per bit}$$

If statistical health validation fails, the gateway halts immediately, emitting `RECEIPT_ENTROPY_INSUFFICIENT` or `RECEIPT_ENTROPY_SOURCE_FAULT`.

### 2.3. Stage 3: Cryptographic Conditioning

Raw entropy is conditioned using a non-invertible, post-quantum resilient compression function initialized with host execution context digests (processor CPUID, bus enumeration, firmware commitment):

$$\mathcal{S}_{\mathrm{seed}} = \mathrm{KDF}\Big(\mathcal{B}_{\mathrm{raw}} \,\|\, \mathrm{Digest}(\text{HostContext})\Big)$$

yielding an irreducible 512-bit localized entropy commitment.

### 2.4. Stage 4: Inner-Ring PQC Key Generation

Governed by the {% include term.html id="dual-ring-pqc-boundary" %} (`docs/abstractionLayers.md` §8.3), the gateway parameterizes the local Inner Ring:
- Instantiates a Post-Quantum Cryptography (PQC) keypair ($\mathrm{pk}_{\mathrm{node}}, \mathrm{sk}_{\mathrm{node}}$) using a state-preserving lattice-based or stateless hash-based signature scheme (e.g., ML-DSA / Dilithium or SLH-DSA / SPHINCS+), managed via {% include term.html id="structural-indirection" %}.
- Private root key $\mathrm{sk}_{\mathrm{node}}$ is retained exclusively within the node's local memory substrate (Inner Ring). It is architecturally barred from traversing network boundaries.

### 2.5. Stage 5: Genesis Object Assembly

The local genesis artifact [`Q(0)`]({{ '/glossary.html' | relative_url }}#q0) is assembled in accordance with the {% include term.html id="universal-envelope" %}.

### 2.6. Stage 6: Sealing and Receipt Emission

The gateway signs the initialization event, writes the node genesis {% include term.html id="receipt" %}, and locks $Q(0)$ into an immutable `SEALED` lifecycle state.

### 4.1. Causal Derivation

$$\mathrm{Parent}(Q(1)) = \{ Q(0) \}$$

### 4.2. Physical Calibration of the Abstract Compute Unit $U$

The transition from $Q(0)$ to $Q(1)$ defines the abstract compute unit $U$. To maintain physical realizability across heterogeneous hardware architectures (ARM, x86, RISC-V):

- **Thermodynamic Grounding:** $U$ is calibrated as the governed computational work required to perform an irreversible bit-transition at standard ambient temperature ($T = 300\text{ K}$), bounded by Landauer's dissipation limit:

$$W(U) \ge k_B T \ln 2 \approx 2.87 \times 10^{-21} \text{ Joules}$$

- **Platform Invariance:** In software execution, $U$ represents the baseline unit cost assigned to a single primitive discrete arithmetic morphism (such as integer successor evaluation). - **Identity vs. Unit Measure:** Local entropy seeds parameterize the cryptographic identity of $Q(1)$, but cannot mutate its unit value. $Q(1)$ evaluates identically to metric magnitude $q = 1$ on every node.
