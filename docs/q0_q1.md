## 2. Layer 0 to Layer 1 Gateway: Node Onboarding Protocol

The {% include term.html id="simemp-gateway" %} bridging {% include term.html id="layer-0" text="Layer 0" %} and {% include term.html id="layer-1" text="Layer 1" %} enforces physical-to-governed onboarding through a deterministic pipeline:

```
               NODE ONBOARDING STATE MACHINE
 [START]
    │
    ▼
 (Stage 1: Raw Entropy Harvesting) ──► Fault ──► [RECEIPT: ENTROPY_SOURCE_FAULT]
    │
    ▼
 (Stage 2: Statistical Health Tests) ─► Fault ──► [RECEIPT: ENTROPY_INSUFFICIENT]
    │
    ▼
 (Stage 3: Cryptographic Conditioning)
    │
    ▼
 (Stage 4: Inner-Ring PQC Keygen) ───► Fault ──► [RECEIPT: PQC_KEYGEN_FAILURE]
    │
    ▼
 (Stage 5: Genesis Object Q(0) Assembly)
    │
    ▼
 (Stage 6: Sealing & Receipt Emission) ──► Fault ──► [RECEIPT: GENESIS_RECEIPT_FAILURE]
    │
    ▼
 [SUCCESS: NODE OPERATIONAL]
```

### 2.1. Stage 1: Physical Entropy Harvesting

The node interrogates native {% include term.html id="layer-0" %} entropy sources:
- Silicon thermal noise, ring oscillator jitter, or shot noise.
- System performance counters and bus timing jitter.

The harvested bitstream must satisfy a baseline sample volume ($N_{\mathrm{sample}} \ge 4096\text{ bits}$).

### 2.2. Stage 2: Statistical Health Tests

Raw entropy is verified against statistical health tests (e.g., NIST SP 800-90B standards):
- Repetition count validation to detect stuck-at hardware faults.
- Adaptive proportion validation to bound statistical drift.
- Min-entropy threshold validation ($H_{\mathrm{min}} \ge 0.85\text{ bits/bit}$).

Failure halts onboarding immediately, emitting a diagnostic {% include term.html id="receipt" %}.

### 2.3. Stage 3: Cryptographic Conditioning

Harvested entropy is conditioned via a collision-resistant compression function initialized with execution context digests:

$$\mathcal{S}_{\mathrm{seed}} = \mathrm{KDF}\Big(\mathcal{B}_{\mathrm{raw}} \,\|\, \mathrm{Digest}(\text{HostContext})\Big)$$

producing a localized, non-invertible seed commitment.

### 2.4. Stage 4: Inner-Ring PQC Key Generation

Governed by the {% include term.html id="dual-ring-pqc-boundary" %} ([`docs/abstractionLayers.md`]({{ '/abstractionLayers.html' | relative_url }}) §8.3), the gateway parameterizes the local Inner Ring:
- Generates root keys `(pk_node, sk_node)` using a Post-Quantum Cryptography (PQC) signature scheme managed via {% include term.html id="structural-indirection" %}.
- Private root key `sk_node` is retained exclusively within local memory, barred from public network exposure.

### 2.5. Stage 5: Genesis Object Assembly

The local genesis artifact {% include term.html id="q0" text="Q(0)" %} is constructed under the canonical 9-block {% include term.html id="universal-envelope" %}.

### 2.6. Stage 6: Sealing and Receipt Emission

The gateway signs the initialization record, writes the node genesis {% include term.html id="receipt" %}, and locks $Q(0)$ into an immutable `SEALED` lifecycle state.
