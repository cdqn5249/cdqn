Operates 100% locally on the device registers without network consensus. The local key is constructed by using real physical hardware noise e_harvest as the LWE error distribution:

Local Key Formula: A · s_i + e_harvest,i = b_i (mod q)

9.2 Ring 2: CDQN Network Mesh Qnet(crypto)
